# 太阳穴 TempleFix

一个轻量、无广告、尽量不打扰你的 Windows AI 截图翻译工具。

## 为什么叫“太阳穴”？

项目名字来自一次真实得有点荒唐的翻译事故。

我是一名电商美术师。在制作面部按摩仪的商品图时，图片里的 `temple` 明明指人的“太阳穴”，几个翻译工具却不约而同地把它理解成了“寺庙”。

单词没有错，语境全错。

我需要的不是一个只会查词典的工具，而是一个能够结合上下文，判断这里究竟是“太阳穴”还是“寺庙”的翻译工具。

所以，它叫“太阳穴”，英文名叫 TempleFix。

## 为什么有这个项目？

一开始，我只是想做一个自己用的截图翻译工具。

因为公司不允许使用微信，而我试过的其他方案又总有些不顺手：

- 商业截图翻译软件往往过于臃肿；
- 一些免费工具带有广告或不必要的功能；
- 我试过的一些开源方案配置复杂，不太适合普通用户；
- 直接让多模态大模型看图，效果虽然惊艳，速度却很难接受。

于是太阳穴经历了一轮又一轮推倒重来：

- 纯多模态 → 效果很好，但太慢
- 回到 OCR → Windows OCR 对部分语言和艺术字体能力有限
- 寻找增强方案 → 集成开源离线 OCR
- 继续打磨 → 终于变成现在这个版本

最终目标很简单：

**小巧、快速、不打扰用户，解决实际的截图翻译需求。**

## 特点

- 🪶 主程序安装包目前约 3 MB，增强 OCR 按需安装
- 🚫 无广告、无账号系统、无遥测
- 🔌 使用用户自己的大模型 API，不绑定单一服务商
- 🧠 OCR + LLM 纠错与翻译，尽量修正常见识别错误
- 🚀 提供增强离线 OCR，图片识别在本机完成
- 🌏 增强 OCR 支持中、英、日及多种拉丁文字
- 🖼️ 保留可选多模态模式，用于要求更高的精细翻译

## 它不是一个 AI 玩具

太阳穴不是为了展示“让 AI 看图”。

它更关注实际使用体验：

截图 → 本地 OCR → 语义纠错 → 翻译

让 AI 负责它擅长的语言理解，而不是让昂贵、缓慢的多模态模型承担所有工作。

## 你需要准备什么？

太阳穴本身不提供大模型服务，也不经过任何中转服务器。

你需要准备一个大模型服务商提供的 API Key。程序预设了 DeepSeek、豆包、OpenAI、Gemini 和 Anthropic，也可以填写其他 OpenAI 兼容接口。

- DeepSeek：价格和中文处理能力比较均衡，适合作为日常翻译模型。
- Gemini：可以使用 Google 提供的兼容接口；具体额度和可用性以官方政策为准，中国大陆网络环境下可能无法直接访问。

你也可以使用其他兼容服务。

### 自备 API 没有想象中复杂

“需要自备大模型 API”听起来有些技术感，但对普通用户来说，它更像是给软件准备一张按量付费的电话卡，不需要会编程。

以中国大陆用户使用 DeepSeek 为例：

1. 打开 [DeepSeek 开放平台注册页](https://platform.deepseek.com/sign_up)，按页面提供的邮箱或 `+86` 手机号入口完成注册。注册方式可能随所在地区调整，以页面实际显示为准。
2. 如需充值，按照平台提示完成个人实名认证，然后使用支付宝或微信充值。普通个人用户不需要注册企业账号。
3. 在开放平台创建一个 API Key。
4. 回到太阳穴“首选项”，翻译服务选择“自定义”，接口地址填写 `https://api.deepseek.com`，模型名称填写 `deepseek-v4-flash`，再把 API Key 粘贴进去即可。

API Key 相当于账户密码，请只填写在太阳穴的设置里，不要发给别人，也不要贴到公开截图或 GitHub Issue 中。

### 10 元大约能翻译多少次？

以下只估算太阳穴的普通模式，也就是“本地 OCR → 文字纠错与翻译”，不包括直接发送图片的多模态翻译。

根据 DeepSeek [2026 年 8 月 10 日的官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)，`deepseek-v4-flash` 缓存未命中的输入价格为每百万 token 1 元，输出价格为每百万 token 2 元。太阳穴会关闭思考模式。

为了不把数字说得过分漂亮，假设一次普通截图翻译消耗：

- 输入 300 token（提示词和一条短句 OCR 文字）
- 输出 100 token（纠正后的原文和译文）

那么：

```text
一次费用 ≈ 300 ÷ 1,000,000 × 1 元
         + 100 ÷ 1,000,000 × 2 元
         = 0.0005 元

10 元 ÷ 0.0005 元 ≈ 20,000 次
```

所以，在普通短句截图场景下，**10 元人民币可以保守理解为约 2 万次翻译**。较短的句子或缓存命中时，实际次数可能更多；文字越长，次数越少。实际费用以模型返回的 token 用量和 DeepSeek 当时的官方价格为准。

## 下载与使用

从本仓库的 [Releases](../../releases) 页面下载最新 MSI 安装包。

1. 安装并启动太阳穴；程序会常驻系统托盘。
2. 从托盘打开“首选项”，填写模型接口地址、模型名称和 API Key。
3. 如需更可靠的本地文字识别，在“增强离线 OCR”区域点击“一键安装”。
4. 按 `Alt+Z`，框选屏幕内容并翻译。

增强 OCR 组件会显示下载、校验和安装进度。成功或失败都会明确提示，不会静默安装。

## 两种 OCR 方式

### Windows OCR

主程序自带的基础方案，不增加安装体积。识别能力取决于系统已经安装的 Windows OCR 语言组件。

### 增强离线 OCR（选装）

增强组件使用 RapidOCR 3.9.2、PP-OCRv6 small 和 ONNX Runtime CPU。它完全在本机运行，不会从云端获取 OCR 结果。

当前组件包下载约 93 MB，安装后约 207 MB。它覆盖中、英、日及多种拉丁文字，共 50 种语言；韩文、阿拉伯文和俄文等不在当前这套小模型中。

组件安装后会优先使用；组件被关闭、损坏或不支持所选语言时，程序会自动回退到 Windows OCR。它可以单独卸载，不影响主程序和已有设置。

中国大陆用户可通过魔搭 ModelScope 下载组件：[TempleFix RapidOCR Addon](https://www.modelscope.cn/models/lh0227/TempleFix-RapidOCR-Addon)。程序会对下载包同时校验固定体积和 SHA-256，校验通过后才会安装。

## 隐私说明

- Windows OCR 与增强 OCR：截图只在本机处理。
- 普通翻译：只有 OCR 识别出的文字会发送给用户配置的模型服务商。
- 多模态翻译：只有用户主动使用多模态模式时，截图才会发送给相应模型服务商。
- TempleFix 不提供中转服务器，也不收集使用数据。

请勿在公开的问题、日志或截图中泄露自己的 API Key。

## 从源码构建

需要 Windows、Rust 工具链、Tauri 2 所需的系统依赖以及 WebView2。

运行测试：

```powershell
cargo test --manifest-path src-tauri/Cargo.toml
```

构建 MSI：

```powershell
cargo tauri build --manifest-path src-tauri/Cargo.toml
```

增强 OCR 组件的源码、依赖清单和打包脚本位于 `rapidocr-addon` 目录。构建产物不会提交到源码仓库。
