# TempleFix RapidOCR 增强离线 OCR 组件

这是开源截图翻译工具“太阳穴（TempleFix）”的可选 OCR 组件，不是独立应用。

- Windows x64
- 组件版本：3.9.2-1
- 下载包：约 92.9 MiB
- 安装后：约 207 MiB
- 图片识别完全在用户本机执行，不会把截图上传到本仓库或其他服务器

TempleFix 会在下载完成后核对文件体积和 SHA-256，校验通过才会安装。组件 ZIP 内含第三方许可证和版权声明。
